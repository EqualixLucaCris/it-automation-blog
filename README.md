# Blog IT&Automation

A team project to build a technology blog focused on IT, automation, and related topics.

The application will be developed with Python and FastAPI, then published online. The project is also an opportunity for the team to practise software development, collaboration, testing, and CI/CD.

## Project goals

- Build a simple, accessible blog.
- Create pages to browse and read articles.
- Provide a clear structure that can be extended with new features.
- Use Git and GitHub for version control and collaboration.
- Add automated checks before changes are merged into `main`.
- Deploy the application to Render when it is ready.

## Planned technology

- **Backend:** Python, FastAPI
- **Templates and frontend:** Jinja2, HTML, CSS
- **Database:** SQL
- **Testing and quality checks:** to be defined
- **Hosting:** Render
- **Task tracking:** Azure Boards

> This technology list describes the current plan and may change as the project develops.

## Getting started

Setup instructions will be added once the application structure and dependencies have been defined.

## Team responsibilities

The team may organise work around these areas:

- Project coordination
- Backend development
- Frontend development
- Database design
- Testing, quality checks, and publication

Responsibilities are flexible and can change during the project. Team members are encouraged to contribute to code reviews and testing.

## Contribution workflow

1. Create a branch for your change.
2. Make and test your changes.
3. Open a pull request targeting `main`.
4. Review the changes and automated checks.
5. Merge the pull request when it is ready.
